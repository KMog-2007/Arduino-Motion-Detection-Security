# Arduino Motion Detection Home Security System

## 📌 Project Overview

This project is an Arduino-based home security system that uses a PIR (Passive Infrared) motion sensor to detect movement.

When motion is detected, the Arduino activates an alert, such as an LED or buzzer, indicating possible movement in the monitored area.

## 🎯 Objectives

* Detect human movement using a PIR sensor.
* Process the sensor signal using an Arduino.
* Activate an alert when motion is detected.
* Demonstrate a simple and low-cost home security system.

## 🛠️ Components Used

* Arduino Uno
* PIR Motion Sensor
* LED
* Buzzer
* 220Ω Resistor
* Breadboard
* Jumper Wires

## ⚡ Working Principle

The PIR sensor detects changes in infrared radiation caused by a moving person or object.

When motion is detected, the PIR sensor sends a HIGH signal to the Arduino. The Arduino then activates the LED and buzzer as an alert.

When no motion is detected, the alert remains OFF.
